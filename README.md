## Selected domain
Insurance

## Selected AI task
Classification / anomaly-risk detection for claim fraud triage.

## Summary
The proposed solution uses structured insurance claim, policy, customer, and investigation data to classify claim risk. High-risk claims are sent to human reviewers, while low-risk claims can be processed faster. Responsible AI controls include fairness testing, privacy safeguards, explainability, human oversight, and drift monitoring.
